東京旅遊手帳 App 版（PWA）

模組包含：
- 旅行總覽與行程完成進度
- 航班、住宿與四天可編輯行程
- 景點地圖捷徑與餐廳清單
- 旅行預算記帳（日圓／新台幣換算）
- 購物清單、旅程照片、票券／預約資訊
- 行李清單、出發前待辦、列印／PDF、JSON 備份

檔案內容：
- index.html：行程網頁 App
- manifest.webmanifest、sw.js、icon-192.png、icon-512.png：安裝與離線快取所需檔案

重要：要以「可安裝 App」方式加入手機主畫面，通常需要先把整個資料夾部署到支援 HTTPS 的靜態網站空間。單純在手機下載並打開 HTML，仍可閱讀，但不一定能安裝成 App，也不會啟用離線快取。

部署後：
- Android／Chrome：打開網站，點「加到手機主畫面」或瀏覽器選單中的「安裝應用程式」。
- iPhone／Safari：打開網站，點「分享」→「加入主畫面」。

行程、清單、記帳資料及照片會儲存在該裝置／瀏覽器的本機儲存空間，不會自動同步到家人手機。換裝置前請先匯出 JSON 備份；照片需在原裝置瀏覽器中查看。
